# Сборка и проверка

Нужен Node.js 22+. Сборка и модульные тесты используют стандартную библиотеку Node.js; `npm install` для них не требуется.

```sh
npm test
npm run audit:public
```

Тесты проверяют встроенные 1555 ID, форматы и приоритеты баз, одиночную и пакетную подмену, ошибки сети, кэш, обновление базы, обмен между контекстами, MP3/Blob и запуск кода с nonce. Автоматический тест не подтверждает слышимый звук в Safari на настоящем iPhone.

Опциональная проверка сети:

```sh
npm run check:network
```

Она обращается к шести публичным спискам и читает начальную часть одного файла из трёх хранилищ. Отчёт выводится в терминал. Для сохранения задайте `FKC_NETWORK_REPORT` как путь вне каталога публикации. Состав внешних баз может отличаться от снимка; проверка сети не является условием воспроизводимой сборки.

Опциональная проверка CSP:

```sh
npm run check:browser
```

Нужны отдельно установленные Playwright и браузер. Путь к пакету задаётся переменной `FKC_PLAYWRIGHT`, к браузеру — `FKC_BROWSER`. Проверка использует локальные фикстуры через перехват запросов, не входит в аккаунт. Playwright WebKit на компьютере не воспроизводит целиком Safari и Userscripts на iOS. См. [документацию Playwright](https://playwright.dev/docs/browsers#webkit).

В исходной документации проекта записано подтверждение пользователем подмены на iPhone 29.10.2026 без точной версии iOS. Оно не является результатом нового теста подготовленного архива. Проверки продолжения и смены трека при заблокированном экране остаются открытыми.
