# Установка на iPhone и iPad

Нужны Safari, расширение [Userscripts](https://apps.apple.com/app/userscripts/id1463298887), интернет и собственный аккаунт Яндекс Музыки с доступом к веб-плееру. Это установка скриптов для Safari, без IPA и подписи приложения.

## 1. Сохраните два скрипта

В разделе **Releases** этого репозитория скачайте **FkCensor-Userscripts-1.0.1.zip**, сохраните в «Файлы» и нажмите на архив для распаковки. В папке `userscripts` должны находиться:

- `FkCensor-1-player.user.js` — подключение подмены к плееру;
- `FkCensor-2-lists.user.js` — списки, загрузка файлов и диагностика.

До появления релиза эти же файлы можно скачать из папки `userscripts` репозитория через **Raw / Download raw file**. Не сохраняйте HTML-страницу GitHub вместо JavaScript. Сохраняйте имена с окончанием `.user.js`.

## 2. Настройте Userscripts

Откройте приложение Userscripts и через **Set Userscripts Directory / Change Directory** выберите папку `userscripts`. Если папка хранится в iCloud, включите для неё «Сохранять загруженным» или перенесите её в «На iPhone».

Откройте **Настройки → Приложения → Safari → Расширения → Userscripts**, включите расширение. В более старой iOS путь начинается с **Настройки → Safari**. Если используются профили Safari, включите расширение в нужном профиле. См. [инструкцию Apple](https://support.apple.com/guide/iphone/get-extensions-iphab0432bf6/ios).

## 3. Откройте музыку

Перейдите в Safari на [music.yandex.ru](https://music.yandex.ru/) и войдите в собственный аккаунт. Откройте меню расширений Safari, затем Userscripts. Включите оба скрипта **FkCensor iOS — 1. Подмена** и **FkCensor iOS — 2. Списки и проверка**. После копирования или замены файлов откройте это меню хотя бы один раз и перезагрузите вкладку.

Разрешите Userscripts работать на используемом домене Яндекс Музыки. По запросу расширения разрешите загрузку с `raw.githubusercontent.com`, `huggingface.co` и его серверов выдачи файлов (`hf.co`, `xethub.hf.co`, `cdn-lfs.huggingface.co`, `cas-bridge.xethub.hf.co`). Они нужны для публичных списков и MP3. Логин, пароль и токен в сами скрипты вводить не нужно.

Сначала попробуйте мобильную версию. Если сайт предлагает открыть приложение или веб-плеер отсутствует, выберите **«Запросить настольный веб-сайт» / «Версия для ПК»** в меню Safari. Доступность веб-плеера зависит от сервиса, региона и аккаунта.

## 4. Проверьте звук

Внизу справа появится кнопка **FK · 1555**; актуальное число после обновления списков может отличаться. Запустите трек. Нажатие FK открывает отчёт. Для исправного подключения ожидаются строки:

```text
Запуск подмены: выполнен с nonce сайта (1.0.1)
Код страницы: на связи
Подмена в плеере: подключена
```

Для трека из базы появится **«Последняя подмена: <ID>»** и сообщение о передаче файла плееру. Среди записей встроенного снимка есть ID `138629224` и `27317249`. Послушайте соответствующий участок записи: статус подключения сам по себе не доказывает изменение звука. Для трека вне базы остаётся обычное поведение сайта.

Проверьте отдельно текущий трек после блокировки экрана и переход к следующему треку в фоне. Эти режимы не заявлены как проверенные для всех iPhone.

## Если не получилось

| Симптом | Что проверить |
| --- | --- |
| Кнопки FK нет | Выбрана нужная папка, включены два скрипта, разрешено расширение, вкладка перезагружена |
| Нет ответа от первого скрипта | Первый файл полностью скопирован, после замены открыто меню расширения |
| Вставка не выполнена | Перезагрузить вкладку; если повторяется, сообщить версию iOS и строки отчёта FK |
| Код страницы на связи, плеер не найден | Запустить трек, при отсутствии веб-плеера попробовать версию для ПК |
| Нет разрешения GM.xmlHttpRequest | Проверить второй файл и разрешения Userscripts для источников |
| Ошибка файла, остаётся ответ Яндекса | Проверить сеть и доступ к хранилищу; файл мог быть удалён автором базы |
| Готово, подмены не было | Проверить, что ID трека присутствует в базе |

Для сообщения об ошибке достаточно версии iOS, версии Userscripts, ID трека и текста FK. Не прикладывайте cookies, HAR, экспорт аккаунта, весь экран с профилем или содержимое папки браузера.

## Обновление и удаление

Для обновления замените **оба** `.user.js` в выбранной папке, откройте меню Userscripts и перезагрузите музыку. Публичные списки обновляются автоматически, код скриптов обновляется заменой файлов.

Чтобы вернуть обычное поведение сайта, выключите оба скрипта и перезагрузите страницу. Затем можно удалить файлы из выбранной папки; для удаления сохранённого кэша используйте средства очистки данных Userscripts/сайта. Удаление скриптов само по себе не гарантирует очистку хранилища расширения.

Дополнительные сведения: [документация Userscripts](https://github.com/quoid/userscripts#usage), [конфиденциальность](../PRIVACY.md).
