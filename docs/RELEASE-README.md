# FkCensor для iPhone / iPad

Версия 1.0.1. Автор и сопровождающий: [vibemashia / @obamalolka-oss](https://github.com/obamalolka-oss).

1. Установите [Userscripts из App Store](https://apps.apple.com/app/userscripts/id1463298887).
2. Сохраните и распакуйте архив в приложении «Файлы».
3. В Userscripts выберите папку `userscripts` из этого архива.
4. Включите расширение Userscripts в настройках Safari и разрешите его для Яндекс Музыки.
5. Откройте [music.yandex.ru](https://music.yandex.ru/) в Safari, включите **оба** скрипта в меню Userscripts и перезагрузите вкладку.
6. Запустите трек из базы. Кнопка FK показывает результат подключения; подмену проверьте прослушиванием.

[Подробная установка, разрешения и ошибки](docs/INSTALL-IOS.md) · [Авторы и соавторы](CREDITS.md) · [Конфиденциальность](PRIVACY.md) · [Сторонние условия](THIRD_PARTY_NOTICES.md).

В архиве нет аккаунта автора, паролей, браузерных профилей и аудиофайлов. Используйте собственный аккаунт Яндекс Музыки. Списки и запрошенные файлы загружаются из внешних публичных источников; нужен интернет. Работа при заблокированном экране требует отдельной проверки на вашем iPhone.
