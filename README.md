# FkCensor Safari

Подмена отдельных записей в веб-плеере Яндекс Музыки на версии из публичных списков. Работает в Safari на iPhone через расширение **Userscripts**. В комплекте два готовых скрипта; Mac, Xcode и установка приложения из IPA не нужны.

Встроенный снимок содержит **1555 подмен**. Списки обновляются при открытии страницы и возвращении во вкладку. Аудио загружается по запросу плеера. Для воспроизведения нужен интернет и доступ к веб-плееру Яндекс Музыки в своём аккаунте. Подменяются только треки из списков.

**Начать:** [установка на iPhone](docs/INSTALL-IOS.md) · [авторы и источники](CREDITS.md) · [конфиденциальность](PRIVACY.md) · [ограничения и проверка](docs/TESTING.md).

## Установка

1. Установите [Userscripts из App Store](https://apps.apple.com/app/userscripts/id1463298887).
2. Скачайте архив **FkCensor-Userscripts-1.0.1.zip** из раздела **Releases** этого репозитория, сохраните в «Файлы» и распакуйте.
3. В приложении Userscripts выберите распакованную папку `userscripts` как папку скриптов.
4. Включите расширение в **Настройки → Приложения → Safari → Расширения → Userscripts** и разрешите работу на сайте Яндекс Музыки. В старых iOS пункт Safari находится прямо в настройках.
5. Откройте [music.yandex.ru](https://music.yandex.ru/) в Safari, включите оба скрипта в меню Userscripts и перезагрузите страницу.
6. Запустите трек из базы. Кнопка **FK** открывает отчёт; успешное подключение показывает **«готово»**. Саму подмену проверьте прослушиванием.

Если релиз ещё не опубликован, скачайте два файла из папки [userscripts](userscripts/) через **Raw / Download raw file** и сохраните в одну папку. Файлы должны оканчиваться на `.user.js`, без `.txt`.

Подробные разрешения, обновление, удаление и разбор ошибок: [инструкция](docs/INSTALL-IOS.md). Порядок установки соответствует [документации Userscripts](https://github.com/quoid/userscripts#usage).

## Совместимость

Версия скриптов: **1.0.1**. Есть запись об успешной проверке подмены пользователем на iPhone 29 октября 2026 года; версия iOS не зафиксирована. Продолжение и переход к следующему треку при заблокированном экране требуют отдельной проверки. Изменения веб-плеера могут потребовать обновления скриптов.

Поддерживаемые адреса: `music.yandex.ru`, `.com`, `.kz`, `.by`, `.uz`. Это неофициальный проект; он не связан с Яндексом или авторами Userscripts. Доступ к платным функциям сервиса определяется самим сервисом.

## Исходники

Для сборки и автоматических тестов нужен **Node.js 22+**; внешние npm-зависимости не требуются.

```sh
npm test
npm run audit:public
```

`src/` содержит код плеера, загрузки и обмена сообщениями; `data/` — публичные источники и снимок адресов; `userscripts/` — два установочных файла; `Tests/` — проверки. Сборка воспроизводится локально из включённых файлов без сетевых запросов.

Дополнительные проверки: [TESTING.md](docs/TESTING.md). Подготовка публикации и защита личного email в коммитах: [PUBLISHING.md](docs/PUBLISHING.md).
