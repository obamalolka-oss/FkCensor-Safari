# Сообщения о проблемах

Обычные ошибки воспроизведения можно описать в Issues: версия iOS, версия Userscripts, ID записи и текст FK без сведений об аккаунте.

Для уязвимости, затрагивающей аккаунт или приватные данные, используйте **Security → Report a vulnerability**, если сопровождающий включил private vulnerability reporting. Если приватный канал ещё не включён, попросите его включить, не публикуя детали, токены или данные чужого аккаунта в Issues.

Не прикладывайте браузерные профили, HAR, cookies, дампы хранилищ и полные журналы авторизации. При утечке действующего секрета сначала отзовите или замените его. Удаление файла из последнего коммита не удаляет его из истории: [пояснение GitHub](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository).
