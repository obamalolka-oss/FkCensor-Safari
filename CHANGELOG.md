# Изменения

## 1.0.1

- Запуск подмены с nonce сайта и диагностика результата запуска.
- Два самодостаточных скрипта для Safari / Userscripts.
- Встроенный снимок 1555 адресов подмен с обновлением шести публичных списков.
- Передача запрошенного MP3 в плеер через Blob; при сбое загрузки сохраняется исходный ответ сайта.
- Для публикации добавлены инструкции, атрибуция, описание конфиденциальности и аудит состава файлов. Версия исполняемого Safari-кода сохранена.
